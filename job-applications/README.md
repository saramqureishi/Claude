# Job Applications — audit & tracking

Two things live here:

## 1. PROMPT_company_audit.md
Paste into Cowork / Claude Code to work through your target companies (by Batch)
and find current graduate/junior data/AI roles — so you can see which companies
you've missed. Non-banking only, honest about what it couldn't check.

**How to run:** attach `sara_background.md`, `companies.csv`, and
`application_tracker.csv`, then say "Do Batch 7" (or whichever). Work through
batches over several sessions.

## 2. application_tracker.csv
Your master record of what you've applied to and the outcome. Fill it as you go.
Two jobs it does:
- Stops you re-applying to the same role / a company that rejected you.
- Lets you spot PATTERNS (e.g. "I keep getting cut at the online-test stage") so
  you know what to work on.

Outcome values: Not Applied / Applied / Rejected / Assessment / Interview / Offer / No Response
Stage Reached: where it ended — CV screen / online test / video interview / AC / final

## Suggested flow
1. Audit companies batch by batch (prompt #1) → find live roles.
2. Apply → log each application in application_tracker.csv.
3. Later (separate session): run the daily "fresh jobs" feed for new postings.
