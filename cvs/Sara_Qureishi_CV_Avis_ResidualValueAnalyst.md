## MOST RELEVANT PROJECT
**UK Used-Car Value Retention Analysis** — *self-initiated* | Python, SQL, Snowflake, Tableau
GitHub: github.com/saramqureishi/uk-car-value-retention | Dashboard on Tableau Public
- Analysed around 98,000 UK used-car listings in Python to study how vehicle values fall with age,
  mileage and fuel type, treating advertised prices as a proxy and documenting the limitations honestly.
- Showed an apparent hybrid resale advantage was about 60% explained by model mix (hybrids being
  mostly value-holding Toyotas); used a model fixed-effects regression and a cluster bootstrap to
  show the remaining gap was not statistically confirmed.
- Built an Excel value-retention matrix (residual-value proxy) with pivot tables, plus a procurement
  ranking (value retained by model, age and mileage band) with low-confidence cells flagged, and
  rebuilt the pipeline in Snowflake (raw to staging to mart SQL models). Published an interactive
  Tableau dashboard for a non-technical audience.
